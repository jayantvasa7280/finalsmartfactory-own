To run the project locally, we need the following:

1. Azure CosmosDB Emulator: This is the Database wherein the data for the system will be stored
2. Azurite: This will help the Azure Functions run on the system locally

Both of these would be running as Separate Dockeer containers

These are the files provided to you with their descriptions:
1. these files would be under the backend folder of this system: 
    1. setup_db.py: used to create the database "llmops-data" and the list of containers under it.
    2. seed_data.py: used to add the evaluators and templates data into their containers respectively
    3. explore_db.py: used to explore and see the data appended inside of the containers
    4. backend/requirements.txt: This is to install all the softwares required for the backend .venv/
2. azure-functions/requirements.txt: This is to installed all the required softwares into the azure-functions .venv/
3. example_evaluators.json: Contains the data for evaluators
4. example_templates.json: Contains the data for templates

2. Take the .env.example file provided to you and create a copy of that and then replace the placeholder values with the provided key and endpoint values.
3. Make sure you have the following softwares installed in the system:
    a. docker
    b. azure functions Core Tools: npm install -g azure-functions-core-tools@4 --unsafe-perm true
4. Run these commands in the terminal in exact same way:
    a. docker run -d --name=cosmosdb-emulator -p 10251-10251:10251-10251 -p 8081:8081 -m 4g mcr.microsoft.com/cosmosdb/linux/azure-cosmos-emulator:vnext-preview
    b. docker run -d -p 10000:10000 -p 10002:10002 --name azurite mcr.microsoft.com/azure-storage/azurite
    c. cd Desktop/finalsmartfactory-own/backend && python3 -m venv .venv
    d. source .venv/bin/activate && pip install -r requirements.txt
    e. python setup_db.py
    f. python seed_data.py
    g. cd .. && cd azure-functions/
    h. python3 -m venv .venv && source .venv/bin/activate
    i. pip install -r requirements.txt
    j. func start

If you dont want to do all of these steps, you can simply create a bash script of all of these commands and
run that to directly start and setup the database. Keep in mind the following things when creating the bash script:
1. Cosmosdb-emulator docker container takes about 1-2 mins when freshly running the docker run command but provided the docker image is already present, 
it should take about 5-8s to be fully functional.
2. Its the same with Azurite docker container.
3. So its, important to either first download the docker images of both and then creating a bash script with a sleep 7 command to have a delay of
7 seconds before the next command is run.

To start the monitoring system, you need to execute the steps in the same order:
1. cd Desktop/finalsmartfactory-own/backend && source .venv/bin/activate
2. uvicorn main:app --reload
3. cd .. && cd frontend/
4. npm run dev
